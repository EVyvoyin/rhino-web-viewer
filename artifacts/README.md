# 下载文件

当前版本为 **[1.0.3-preview](1.0.3-preview/)**，包含大模型保存修复。

- [viewer.html](1.0.3-preview/viewer.html)：独立 GLB 查看器。
- [打开模型查看器.cmd](1.0.3-preview/打开模型查看器.cmd)：与 viewer.html 放在同一文件夹后双击运行。
- [使用方法.txt](1.0.3-preview/使用方法.txt)：打开、保存和发送给其他电脑的操作步骤。
- [demo.html](1.0.3-preview/demo.html)：带有合成演示模型的网页。
- [RhinoWebViewer.rhi](1.0.3-preview/RhinoWebViewer.rhi) / [RhinoWebViewer.rhp](1.0.3-preview/RhinoWebViewer.rhp)：Rhino 8 安装包与插件。

本目录直接放置的 `viewer.html`、`demo.html` 同步为最新版，方便旧链接继续使用。直接放置的 RHP/RHI 保留为早期版本，安装请使用上面的版本目录。

在 GitHub 文件页面选择 Download raw file 后，用 Chrome 或 Edge 打开 HTML。完整说明和验证范围见[项目说明](../README.md)。
