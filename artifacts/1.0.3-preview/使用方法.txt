Rhino 模型查看器 1.0.3 — 大模型保存修复版

1. 在 Windows 文件资源管理器中双击“打开模型查看器.cmd”。
   它会在 Chrome 或 Edge 中打开同一文件夹的 viewer.html。
   请把启动文件和 viewer.html 放在一起。

2. 点击网页里的“打开模型”，选择你自己的 .glb 文件。
   等待模型显示完成。

3. 点击右上角“保存模型网页”。
   如果弹出保存窗口，先选择保存位置，再等待百分比完成。
   成品名为“你的模型名-360预览.html”。
   若浏览器使用下载方式，可按 Ctrl+J 查看下载位置。
   保存期间画面暂时保持不动，这是为了让大模型顺利写入。

4. 将这个新保存的 HTML 文件发到另一台电脑。
   对方下载后，右键该文件，选择“打开方式 → Google Chrome / Microsoft Edge”。
   模型数据和贴图已包含在 HTML 中，不需要 Rhino。

请使用文件资源管理器中的启动入口。
index.template.html 是开发模板，不是模型查看器成品。
浏览器的“截图”按钮只保存图片；保存三维模型网页请使用“保存模型网页”。
聊天软件内的文件预览不一定运行完整网页，请先下载，再用 Chrome / Edge 打开。
